Dos des cartes

Dessins des 36 cartes

Mode d’emploi

  1. Dans Canva : Partager → Télécharger → PNG, toutes les pages.
  2. Glissez les fichiers ici. Rangez-les par glisser-déposer ou avec les flèches.
  3. Vérifiez le résultat avec Aperçu.
  4. Cliquez sur Publier : tout le monde voit la nouvelle version en une minute environ.

Tant que vous ne publiez pas, vos modifications restent un brouillon enregistré automatiquement sur cet appareil.

Connexion à GitHub

Pour publier, l’atelier a besoin d’une clé d’accès (« jeton ») à votre dépôt GitHub. Elle reste enregistrée uniquement dans ce navigateur.

Comment créer le jeton ?
  1. Ouvrez github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Nom : Atelier du Grimoire. Expiration : à votre convenance (1 an par exemple).
  3. Repository access : Only select repositories → choisissez Book.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Cliquez sur Generate token, copiez-le et collez-le ci-dessous.
